Clinicly assets

Which file to use, version 0.3 (November 12, 2026). Logo files are flat vector art in the exact brand colors with a transparent background: light files are drawn for a light page, dark files for a dark one, and mono files are one-color drawings (Navy Ink or Mist). There is no shape behind any logo except the app tile and the avatar, which are the symbol on a Cornflower or Night High ground. The favicon follows the device theme by itself. Clinicly is a fictional brand, made to give FableBook demo screens a believable clinic app. The name is not cleared: other products already use the name Clinicly.
